# MediBridge v23.5 COMPLETE

Use this package if you want one compiled version.

## What to deploy
- Frontend: deploy this folder only (v23.5 already includes the v23.4 frontend).
- Backend SQL: run `v23-5-complete-backend.sql` once.

## Important
- Do **not** deploy both v23.4 and v23.5 frontends together. Use only v23.5.
- If you already ran v23.4 SQL earlier, you can run only `v23-5-backend.sql` instead.

## Recommended path
- Fresh setup: run `v23-5-complete-backend.sql` and deploy this v23.5 package.
- Existing v23.4 setup: run `v23-5-backend.sql` and replace the frontend with v23.5.
