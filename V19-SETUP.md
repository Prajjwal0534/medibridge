# MediBridge v19 — Follow-up & Reminder System

1. Run `v19-backend.sql` in Supabase SQL Editor.
2. No Edge Function changes are required.
3. Deploy the unzipped v19 folder to Netlify.

What v19 adds:
- Follow-ups tab for patients
- dashboard follow-up summary
- upcoming/overdue counts
- next follow-up date
- timeline of doctor-recorded follow-ups
- View consultation
- Book follow-up
- Dismiss reminder
- automatic backfill of existing consultation follow-up dates

Test with the existing consultation that already has a follow-up date.
